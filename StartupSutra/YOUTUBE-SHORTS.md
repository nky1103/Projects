# StartupSutra — YouTube Shorts kit (Week 3)

Each reel now has a music version at `reels/reel-yt.mp4` (the silent `reel.mp4`
stays for Instagram, where you add trending audio). Upload `reel-yt.mp4` to
YouTube as a **Short** (it's 1080×1920, 22s, so YouTube auto-classifies it).

**Why bother:** YouTube is a search engine, so Shorts keep pulling views for
months (unlike IG, which dies in a day). Free extra reach on content you already
made.

## How to use each entry
- **Title** goes in the title field (keep `#Shorts` in it).
- **Description** goes in the description box.
- **Tags** go in the tags field (Settings → Tags), comma-separated.
- After posting, **pin the first comment** with the same YES/NO question from the
  Instagram kit (it works on YouTube too).
- CTA is **Subscribe** on YouTube (not "Follow").

## Posting cadence
Mirror the IG schedule: post that day's Short the same day. To build a library
fast, you can also backfill 1–2 older Shorts per day. Don't dump all at once.
