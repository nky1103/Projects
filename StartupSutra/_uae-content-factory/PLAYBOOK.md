# StartupSutra UAE — Content Playbook (locked 2026-09-18)

Position: **Dubai / UAE real-estate INTELLIGENCE** — not another generic property page.
Goal metric: **sends + saves** (Mosseri: watch time, likes, sends drive reach; sends reach non-followers). Views alone are not the KPI.

## Reel formula (every reel)
HOOK → SURPRISE → PROOF → IMPLICATION → SAVE/SEND CTA
- **Frame 0 = the number.** Lead with the raw, surprising stat on a near-black screen. NO skyline/brand establishing first. (Engine: set `reveal:{at,dur}` so the Dubai scene stays dark through the hook, then reveals.)
- **Make it sendable:** frame the stat as a tangible contrast someone DMs a friend ("AED 1M buys 1,370 sq ft here… 260 there").
- **CTA = an action, never navigation.** "Save this before your next Dubai search" / "Send this to someone buying in Dubai" / "Which zone would you choose? 👇". NEVER "Swipe the carousel".
- Reference the carousel softly: "Full breakdown → @statupsutra".

## Carousel = its own story (not the reel animated)
Cover must be a hook, not a title. Use tension framing: "131,000 homes. 31% in 5 areas. Opportunity or oversupply?" Numbers on every slide + 01/NN counters + source line.

## Captions: minimal, support don't carry
Short. The reel does the work. End with a save/follow line.

## Hashtags: exactly 5, topic-specific, rotated (never the same 5). No #fyp/#viral/#trending/#explore/#reels.
- Price comparison: #DubaiRealEstate #DubaiPropertyPrices #DubaiPropertyInvestment #DubaiPropertyMarket #DubaiRealEstateInvesting
- Supply/area (e.g. JVC): #DubaiRealEstate #JVC #JVCProperty #DubaiPropertyMarket #DubaiPropertyInvestment
- Rental yield: #DubaiRealEstate #DubaiRentalYield #DubaiPropertyInvestment #DubaiInvestors #UAERealEstate

## Track after each post (send Insights)
avg watch time · 3-sec view rate · completion rate · SHARES/sends (🚨) · saves · likes/reach · non-follower reach · profile visits · follows.

## Data rule
Every number sourced (SOURCES.md per post). No em dashes. Owl logo stays.

## Reel refinement (2026-09-18)
- For any contrast/comparison reel, use an animated BAR-RACE beat mid-reel (e.g. Intl City 1,370 sq ft vs Palm 260 sq ft) — a visual, not another text card. This is what makes it feel like a reel.
- Reel CTA can be a COMMENT prompt ("Where would you put AED 1M? Comment the zone") to drive comments; put Save + Send in the caption.
