# StartupSutra — Brand Assets

Official identity: **the owl mascot** (wisdom = *Sutra*, the thread of distilled
knowledge). Round-glasses eyes nod to the analyst/founder character; built from
the locked brand system — navy `#0b0e14` + amber `#f59e0b`→`#ea580c`. All assets
are hand-built vector (HTML/CSS/SVG), fully editable — no AI generation.

## Which file goes where

| File | Use |
|---|---|
| `mascot-owl-avatar.png` | **Instagram profile picture** — full-bleed, reads down to 64px. Upload this one. |
| `mascot-owl-tile.png` | App icon / large square (owl on tile, floating on navy). |
| `logo-horizontal.png` | Website header, email signature, press, YouTube banner. |
| `logo-stacked.png` | Story-highlight covers, general square logo, reel end-cards. |
| `mascot-owl-source.html`, `logo-lockup-source.html` | Editable vector sources. |

## Usage rules
- The owl mark is **always amber tile + dark owl** (or dark owl on amber) — never
  recolor the owl itself. The mascot is the master brand and stays amber across
  all four series.
- Minimum avatar clear space: none needed (full-bleed by design).
- Do not stretch, add effects, or place the owl on busy backgrounds.
- Series color (red/blue/green) applies to *content* accents, never the mascot.
